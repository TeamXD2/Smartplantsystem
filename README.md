# Smartplantsystem
Creating a system regarding Smart Ground-Truthing and Digital Biodiversity System for Plant Species

## Project structure
- `backend/` — Node.js + Express API using Supabase (Postgres database + photo storage). **Start here:** see [backend/README.md](backend/README.md) to set it up and test it.
- `sprint1_database_schema.sql` — Supabase (PostgreSQL) schema (run it in the Supabase SQL Editor).
